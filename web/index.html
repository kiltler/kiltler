Нужно один раз настроить Firebase Web

Скопируй этот файл к себе на компьютер, открой его в текстовом редакторе, и в самом верху <script type="module"> подставь свой firebaseConfig. Получить его можно так:

  1. Зайди в Firebase Console → Project Settings → Your apps
  2. Кнопка Add app → Web (</>). Имя можно любое, например web-editor.
  3. Скопируй объект firebaseConfig и вставь в этот файл вместо плейсхолдера.
  4. В Authentication → Sign-in method включи Anonymous (если ещё не включено).

Также убедись, что Firestore Rules разрешают чтение/запись коллекции sync анонимным пользователям — то же самое, что использует приложение на телефоне.
