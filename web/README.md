# Веб-редактор «Ассистент»

Одностраничный редактор данных приложения для компьютера. Открывается
в браузере, читает и пишет тот же документ синхронизации в Firestore,
что и Android-приложение, — значит, изменения с компьютера через пару
секунд появляются на телефоне.

## Что внутри

- `index.html` — самодостаточная страница: HTML + CSS + JS в одном файле,
  Firebase JS SDK подгружается с CDN.
- Поддерживаются все сущности из приложения: заказы, напоминания,
  материалы, места работы, расходы. Под капотом — тот же JSON-снимок,
  что приложение пушит в Firestore коллекцию `sync`.

## Разовая настройка

Файлу нужен `firebaseConfig` web-приложения из консоли Firebase
(Android-ключ из `google-services.json` для web-SDK не подходит).

1. Открой Firebase Console для проекта **kiltler**:
   <https://console.firebase.google.com/project/kiltler/settings/general>
2. В разделе *Your apps* нажми **Add app → Web (`</>`)**.
   Имя — любое (например, `web-editor`). Firebase Hosting подключать
   не обязательно.
3. Скопируй выданный объект `firebaseConfig` (выглядит так:
   `{ apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId }`).
4. Открой `index.html` в текстовом редакторе. Сверху в `<script type="module">`
   замени заготовку:
   ```js
   const firebaseConfig = {
     apiKey: "PASTE_WEB_API_KEY_HERE",
     ...
     appId: "PASTE_WEB_APP_ID_HERE"
   };
   ```
   на свой объект из шага 3.
5. В Firebase Console включи анонимный вход:
   *Authentication → Sign-in method → Anonymous → Enable.*
   На Android-приложение он уже работает, так что обычно уже включён.

## Как пользоваться

1. Открой `index.html` двойным кликом — он работает прямо из файловой
   системы. Если хочется доступ с любого ПК, можно один раз залить файл
   на Firebase Hosting или GitHub Pages.
2. В поле «Код синхронизации» вверху введи тот же код, что в настройках
   приложения на телефоне (Меню → Настройки → Синхронизация).
3. Жми «Подключиться». Через пару секунд таблицы заполнятся текущими
   данными с телефона.
4. Редактируй прямо в ячейках, добавляй/удаляй строки. Сверху появится
   жёлтая пометка «несохранённые изменения».
5. Кнопка **«Сохранить в облако»** пушит весь снимок обратно в Firestore.
   Телефон через секунду подтянет изменения.

## Важно

- Синхронизация работает **полным снимком**: при сохранении весь набор
  данных перезаписывается. Если в момент сохранения телефон тоже что-то
  меняет — последняя запись побеждает. Это то же поведение, что между
  двумя телефонами.
- Если данные на телефоне поменялись, пока ты редактировал на компьютере,
  редактор покажет «облако обновилось, но есть локальные правки». Нажми
  «Обновить», чтобы перетянуть свежий снимок (твои правки в редакторе
  при этом потеряются), либо сохрани свои — и они затрут изменения на
  телефоне.
- Файл хранит только последний введённый код в `localStorage` браузера.
  Никакие данные локально не сохраняются — всё живёт в Firestore.
