# BodyQuest ⚔️

Полностью **офлайн** нативное Android-приложение: фитнес-трекер в виде RPG.
Качаешь персонажа от **Новобранца** до **Легенды** через тренировки, замеры и питание.

- **Без интернета, без аккаунтов, без облака.** Все данные — локально на телефоне (Room).
- Тёмная игровая тема, Jetpack Compose + Material 3.
- Package: `com.bodyquest.app`

## RPG-механики

- **5 характеристик** (💪 Сила, 🫁 Выносливость, 🤸 Мобильность, 🔥 Дисциплина, 🛡️ Композиция) —
  у каждой свой уровень и XP-полоса; радар-диаграмма на «листе героя».
- Общий уровень = функция суммарного XP. Порог: `round(100 * level^1.5)`.
- **Ранги:** Новобранец (1–4) → Боец (5–9) → Атлет (10–19) → Воин (20–34) → Чемпион (35–49) → Легенда (50+).
- Тренировки = **квесты**; раз в неделю — **Босс**.
- **Серия дней** (streak): множитель XP +5%/день, максимум +50%.
- **Прогрессия нагрузки**: хранятся вес/повторы/время по упражнениям, подсказка «Прокачка упражнения!».
- **Достижения** (сетка бейджей), анимация XP и модальное окно **Level Up**.

## Как открыть и запустить

1. **Android Studio** (Ladybug 2024.2.1 или новее), JDK 17 (идёт в комплекте).
2. `File → Open` → выбрать корень проекта. Gradle wrapper подтянет Gradle 8.11.1 сам.
3. При первом синке Android Studio скачает Android SDK (API 35) и зависимости (AndroidX, Compose, Room) с Google Maven.
4. Запуск: выбрать эмулятор (API 26+) или подключить телефон → ▶ **Run 'app'**.
5. Сборка из консоли:
   ```bash
   ./gradlew assembleDebug      # debug APK → app/build/outputs/apk/debug/
   ./gradlew lint
   ```

> ⚠️ Для сборки нужен доступ к **Google Maven** (`dl.google.com`, `maven.google.com`) и установленный
> **Android SDK** — там лежат AGP, AndroidX, Compose и Room. На обычной машине / в Android Studio это есть «из коробки».

## Дисклеймер

Перед началом тренировок проконсультируйтесь с врачом. Не тренируйтесь через боль.
Расчёт калорий — здоровый: дефицит 15–20%, но **никогда ниже BMR и ниже 1700 ккал**.
