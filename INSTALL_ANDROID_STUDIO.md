# Установка приложения через Android Studio

Гайд по тому, как склонировать проект, открыть его в Android Studio,
собрать и запустить приложение на эмуляторе или физическом устройстве.

## 1. Что понадобится

- **Android Studio** — последняя стабильная версия: <https://developer.android.com/studio>
- **JDK** — поставляется вместе с Android Studio, отдельно ставить не нужно.
- **Git** — для клонирования репозитория: <https://git-scm.com/downloads>
- Около 8–10 ГБ свободного места (IDE + SDK + эмулятор).

## 2. Установка Android Studio

1. Скачайте установщик с официального сайта и запустите его.
2. На шаге **Install Type** выберите **Standard** — IDE сама докачает
   нужные компоненты: Android SDK, эмулятор, образ системы.
3. Дождитесь окончания загрузки SDK (первый запуск занимает несколько минут).

## 3. Получение исходного кода

### Вариант А — клонировать прямо из Android Studio

1. Откройте Android Studio → экран **Welcome**.
2. Нажмите **Get from VCS** (Version Control).
3. В поле URL вставьте адрес репозитория:

   ```
   https://github.com/kiltler/kiltler.git
   ```

4. Укажите папку для проекта и нажмите **Clone**.

### Вариант Б — клонировать через терминал

```bash
git clone https://github.com/kiltler/kiltler.git
cd kiltler
```

Затем в Android Studio: **File → Open** и выберите папку проекта.

## 4. Синхронизация проекта (Gradle Sync)

При первом открытии Android Studio автоматически запустит **Gradle Sync** —
скачает все зависимости и настроит проект.

- Дождитесь сообщения **"Gradle sync finished"** внизу окна.
- Если синхронизация не началась сама — нажмите кнопку
  **Sync Project with Gradle Files** (значок слона на панели инструментов).
- При запросе установить недостающие SDK / Build Tools — соглашайтесь.

## 5. Настройка устройства для запуска

### Эмулятор (виртуальное устройство)

1. Откройте **Device Manager** (правая панель или **Tools → Device Manager**).
2. Нажмите **Create Device**, выберите модель (например, Pixel 7).
3. Выберите образ системы (рекомендуется последний стабильный API),
   при необходимости скачайте его кнопкой **Download**.
4. Завершите создание устройства — оно появится в списке.

### Физическое устройство

1. На телефоне включите **Режим разработчика**:
   Настройки → О телефоне → 7 раз нажмите на **Номер сборки**.
2. В **Настройки → Для разработчиков** включите **Отладку по USB**.
3. Подключите телефон кабелем и подтвердите доверие компьютеру.

## 6. Сборка и запуск

1. В выпадающем списке вверху выберите устройство (эмулятор или телефон).
2. Нажмите кнопку **Run** (зелёный треугольник) или `Shift + F10`.
3. Android Studio соберёт APK и установит приложение на устройство.

## 7. Сборка APK / AAB вручную

Через меню:

- **Build → Build Bundle(s) / APK(s) → Build APK(s)** — получить `.apk`.
- **Build → Generate Signed Bundle / APK** — собрать подписанную сборку
  для публикации.

Через терминал (из корня проекта):

```bash
./gradlew assembleDebug     # отладочный APK
./gradlew assembleRelease   # релизный APK
```

Готовый файл появится в `app/build/outputs/apk/`.

## 8. Частые проблемы

| Проблема | Решение |
|---|---|
| Gradle sync падает | **File → Invalidate Caches / Restart** |
| Не та версия JDK | **Settings → Build Tools → Gradle → Gradle JDK** |
| Устройство не видно | Проверьте отладку по USB и кабель; выполните `adb devices` |
| Не хватает SDK | **Tools → SDK Manager** — установите нужный API уровень |
| Долгая первая сборка | Это нормально — зависимости кэшируются и далее быстрее |

---

Если в репозитории появится конкретный код приложения (модуль `app`,
файлы `build.gradle`), гайд можно дополнить точными версиями SDK,
minSdk/targetSdk и инструкциями по конфигурации именно этого проекта.
